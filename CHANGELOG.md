# Changelog

## [1.0.0] — November 2026

### Added
- Shader cache cleanup with one-click removal of stale compiled shaders
- Config optimizer that flags and tunes frame-pacing-related values
- Frametime logger with 1% lows and stutter count during real matches
- CPU/GPU presets for low-end and high-end machines
- Backup and restore with timestamped copies before every change
- Before-and-after frame time graph
- Native C++ build, 6 MB, no runtime dependencies
